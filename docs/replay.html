🔧 Shared infrastructure (both phases)

The same RL loop and pipeline power both phases; only the scale changes. The table below is the full side-by-side.
  • 🔁 RL loop: a policy acts in an environment, receives a reward, and is updated by a PPO-family method (PPO for the CNN, GRPO for the LLM).
  • 🪵 Per-step logging: every checkpoint is evaluated and written to a tidy metrics.json (one schema for both phases).
  • 🎬 This replay theater + eyeball plots: the same viz and matplotlib plots render either phase.
  • 🧷 Reproducible runner: gated run.sh, a resumable benchmark, a stall watchdog, and per-process logs.
