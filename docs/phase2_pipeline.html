🧠 The RL environment . the engine of this project

How this differs from straightforward training + evaluation: the model is never shown a correct answer to copy. It generates its own answers and a rule-based verifier scores each one (reward 1 if the final number/letter is right, plus a small format reward); GRPO then pushes the policy toward the higher-reward answers. The reward IS the environment, and the 5 benchmarks test whether that reward-driven skill transfers, not whether it memorized labels.

📋 What each stage does

📦Install deps
Set up the GPU env: torch 2.11+cu128 (already on the box) plus trl / peft / lm-eval / tensorboard.
🧪Sanity gate
A short GRPO run to prove the loop trains and the reward actually moves before committing to the long run.
🏋GRPO train (500)
The RL loop itself: generate answers, verifier scores them, GRPO updates the LoRA policy toward higher reward. 500 optimizer steps.
🧫Eval (5 benchmarks)
lm-eval scores base (pre) vs GRPO (post) on GSM8K, MMLU, ARC-Challenge, HellaSwag, TruthfulQA. Tests transfer of the reward-driven skill.
📊Export metrics
Turn the eval JSONs into a tidy series + a base/post/delta table for the report and the viz.
🎨Wire replay.html
Inject the real numbers into the main dashboard's Phase 2 tab (window.DATA_METRICS_P2).
🚀Commit + push
Publish the adapter-free results (metrics + report) to GitHub. Manual, you run git_push.sh.
